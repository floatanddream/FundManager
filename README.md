# FundManager

中国场外公募基金的**持仓穿透与风险分析**工具。本地运行，自行部署。

> **项目处于早期开发阶段。** 当前版本支持本地账本、基金查询、净值走势图、流水录入、份额对账和单基金风险展示。

---

## 它解决什么

常见的基金 App（支付宝、天天基金、各类记账工具）做的是**记账 + 展示**：告诉你买了什么、赚了多少。以下三件事它们基本不做：

**一、不穿透。** 名称含「联接」的基金不直接持股，它买的是对应的 ETF。实测 `011609 易方达上证科创50联接C` 的「股票仓位」字段显示 **0.41%**，而它实际通过 `588080 科创50ETF易方达` 满仓科创50。按字段字面理解会得出荒谬结论。

**二、不做组合级风险。** 只看单只基金涨跌，不算你手里的钱**叠加起来**处在什么位置——相关性多高、重仓股重叠多少、极端行情下一起跌多少。

**三、不做归因。** 今天跌了，不说是市场跌、行业跌、还是这只基金自己出了问题。

**本项目的目标不是「更好的记账工具」，而是投研视角的组合透视。**

---

## 功能路线

- **真实收益** — 区分资金加权（XIRR，这笔钱实际赚多少）与时间加权（TWR，基金经理行不行）
- **组合级风险** — 波动率、最大回撤及修复期、相关性矩阵、穿透后持仓重叠度
- **压力测试** — 把历史崩盘情景套到当前组合上
- **归因式预警** — 每条预警附带归因分解
- **决策辅助** — 加仓前告知影响，换基时比较相关性与重叠度而非收益排名

---

## 它明确不做

| 不做 | 原因 |
|---|---|
| **不下单** | 不接触任何交易接口，不存储平台凭证，不模拟客户端操作。涉及资金的自动化容错率为零 |
| **不预测涨跌** | 不输出「某基金将上涨/下跌」，界面文案也不暗示预测能力。只做：描述当前风险、蒙特卡洛概率区间、历史情景压力测试 |
| **不接入账户** | 不要求支付宝/天天基金的账号密码。持仓由你手工录入一次，之后只记增量 |
| **不给主动基金估值** | 主动基金季报持仓最长滞后约 4.5 个月，估算没有意义。只有指数基金/ETF 联接能算盘中估值 |

系统的定位是**参谋**：出主意、算后果、给建议。扳机由你扣。

## 部署方式

在仓库根目录执行 `pnpm install`，然后运行 `pnpm dev` 同时启动前后端。浏览器打开 <http://localhost:3001>，后端 API 默认监听 <http://localhost:3000>。端口和部署配置见 [前端启动说明](apps/web/README.md)。

**自行部署，数据留在本机。** 设计上不假设有中心服务器。

- 数据存本地 SQLite，不上传
- 不需要注册账号
- 不把持仓数据发给任何第三方（包括通知渠道：默认用桌面通知，不走会外发数据的推送服务）

## 技术栈

```
运行时    Node 24（原生执行 .ts、原生 fetch、原生 node:sqlite）
后端      Fastify + Service / Repository 分层
数据库    node:sqlite + Drizzle ORM
前端      React + Vite + shadcn/ui + ECharts
测试      Vitest
```

不依赖 Redis、不需要编译原生模块。详见 [`docs/CONSTRAINTS/README.md`](docs/CONSTRAINTS/README.md)。
