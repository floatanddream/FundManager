# 服务端 API 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 `apps/server` 长出 Service 与只读 REST——数据取得到、账算得出，但**没有任何东西把它们串起来给用户看**，本计划补上这一层。

**Architecture:** `Route → Service → { Repository | DataSource | core }`。Service 只搬运、不写算式（§二 规则 1）；所有计算调 `@fundmanager/core`。装配点只有一处 `app.ts`。**每个来自外部数据的数字都带出处与时点**（`stale` / `loss` / `dataAsOf`），这是本层存在的理由。

**Tech Stack:** Fastify 5 · `@fastify/cors`（**需新装**）· Zod · Vitest · Node 24 原生 `.ts` · Drizzle + node:sqlite（已有）

**Spec:** `docs/superpowers/specs/2026-11-19-api-design.md`（权威设计，动手前必读）

## Global Constraints

- **Service 不写算式**（§二 规则 1）。`derivePosition` / `xirr` / `maxDrawdown` 等一律从 `@fundmanager/core` 调
- **风险指标只接受复权序列**（`AdjustedNav`），必须经 `toAdjustedSeries` 产出。**未复权净值喂进风险函数编译不过**
- **XIRR 的期末市值 = 未复权单位净值 × 份额** —— 不能用复权净值，否则分红与现金流重复计入
- **路由按资源归属划分**：账本内数据（持仓/流水/对账/组合风险/XIRR）挂 `/api/ledgers/:ledgerId`；市场数据（搜基金/档案/净值/单基金风险）挂 `/api/funds`。净值与账本无关，不要硬塞 `ledgerId`
- **`stale` 必须穿透到响应**，不能因为「反正有值」就当成新鲜数据（反目标 A3）
- **算不出来返回 `value: null` + `reason`，不是 0**（§8.3）
- **`core` 抛的 `TypeError` 必须翻译**成可操作的中文提示，映射集中一处
- 相对导入带 `.ts` 后缀；不用装饰器；显式列名导出
- **测试要短**（§8.10）：不写 `describe`、造数据用助手、同类断言合并；测试名中文
- **测试要克制**（§8.8）：判据是「会不会在真实使用中静默产生错值」
- **最简优先**（§9.5）：省结构不省做工
- 提交信息**不加任何工具署名**；只 `git add` 本任务文件，**禁 `git add -A`**

## Review Focus

规格未写明、但最可能咬人的五类，**每条都在所属任务里配了测试**：

1. **复权接线漏掉**：`navHistory` 给的是未复权 `rows`，若 Service 直接 `rows.map(r => r.nav)` 传给风险函数 —— 编译期会被 `AdjustedNav` 拦住，但有人会顺手 `as unknown as` 绕过。**风险端点的输出必须能区分「这是复权的」**
2. **XIRR 用复权净值当期末市值** —— 分红已作为现金流计入，再用复权净值就是**同一笔算两次**，收益率虚高。**要断言期末市值的来源**
3. **`stale` 在派生值里丢失** —— 底层 `stale: true` 被 Service 吞掉，用户看到 `stale: false` 的风险数字
4. **坏数据先落库再报错** —— `sequence` 冲突/超赎在**提交前**就该拦，不能存进去再等推导时炸（之后每条路由都失败）
5. **错误原文直出** —— `core` 的「赎回 120 份但账面只有 100 份」原样吐给用户，看起来像系统故障而不是录入错误

### Task 1: `Sourced` 信封与错误翻译

**Files:**
- Create: `apps/server/src/envelope.ts`、`apps/server/src/errors.ts` 及各自 `.test.ts`
- Modify: 根 `apps/server/package.json`（装 `@fastify/cors`）

**Interfaces:**
- Produces:
  - `type Sourced<T> = { value: T | null; reason: string | null; source: string; dataAsOf: string; capturedAt: string; stale: boolean; loss: string | null; provenance: readonly Sourced<unknown>[] }`
  - `fromFetched<T>(f: Fetched<T>): Sourced<T>` —— 把数据源的 `Fetched` 转成信封（`reason: null`、`provenance: []`）
  - `fromDerived<T>(value: T | null, reason: string | null, inputs: readonly Sourced<unknown>[]): Sourced<T>` —— 派生值：`dataAsOf` 取**最早**输入，`stale` 取**任一** true，`loss` 用 `；` 拼接
  - `toHttpError(e: unknown): { status: number; message: string }`

- [ ] **Step 1: 写失败的测试**

```ts
import { expect, it } from 'vitest'
import { fromDerived } from './envelope.ts'

const src = (dataAsOf: string, o: { stale?: boolean; loss?: string | null } = {}) => ({
  value: 1, reason: null, source: 'f10/lsjz', dataAsOf,
  capturedAt: '2026-11-19T10:00:00+08:00', stale: o.stale ?? false,
  loss: o.loss ?? null, provenance: [],
})

it('派生值的 dataAsOf 取最早的那个输入', () => {
  expect(fromDerived(42, null, [src('2026-09-30'), src('2026-11-18')]).dataAsOf).toBe('2026-09-30')
})

it('任一输入 stale，派生值就 stale', () => {
  expect(fromDerived(42, null, [src('2026-09-30', { stale: true }), src('2026-11-18')]).stale).toBe(true)
  expect(fromDerived(42, null, [src('2026-09-30'), src('2026-11-18')]).stale).toBe(false)
})

it('各输入的 loss 拼接带出；全空则 null', () => {
  const r = fromDerived(42, null, [src('2026-09-30', { loss: '仅前十大' }), src('2026-11-18', { loss: '净值缺分红字段' })])
  expect(r.loss).toBe('仅前十大；净值缺分红字段')
  expect(fromDerived(42, null, [src('2026-09-30')]).loss).toBeNull()
})

it('算不出来时 value 为 null 且带 reason', () => {
  const r = fromDerived<number>(null, '成本未知', [src('2026-09-30')])
  expect(r.value).toBeNull()
  expect(r.reason).toBe('成本未知')
})
```

- [ ] **Step 2: 跑测试确认失败** → **Step 3: 实现 `envelope.ts`**

`errors.ts` 的映射表（设计 §八）：超赎 → 400「这笔赎回超过了账面份额，请先补录买入」；同日缺 `sequence` → 400「同一天有多笔流水，需要指定先后顺序」；同日 `sequence` 重复 → 400「同一天的顺序号重复了」；缺必填字段 → 400「这笔记账缺少份额」；**其他 `TypeError` → 400 + 原文**（未知错误不能吞掉，但要标成 400 而非 500）；非 `TypeError` → 500 + 通用提示。
