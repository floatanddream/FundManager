# 账本总览与持有基金列表实施计划

> 执行时按仓库 §9.4 使用子代理逐项实施，全部任务完成后统一审查。共享契约和公共导出涉及的任务串行执行。

**目标** 账本首页显示基金总市值和最新确认日收益。持仓表逐只显示市值、当日收益、持有收益和投资方向标签。

**架构** 延续 Route → Service → Repository / DataSource / core。后端计算、汇总并返回已有的 `Sourced` 信封，前端负责展示。先交付总览和收益，再接板块。申购金额录入用同一套确认净值和账本校验，排在后面。

**技术栈** Node 24、TypeScript strict、Fastify、SQLite、Vitest、React、TanStack Query、Vite。

## 页面和数据口径

| 位置 | 展示 | 口径和缺值 |
| --- | --- | --- |
| 账本总览 · 基金总市值 | 人民币金额 | 同一净值日的开放持仓市值。账本当前没有现金余额字段。部分持仓无法计价时写「已确认部分」和覆盖只数。空仓市值为 0。 |
| 账本总览 · 当日收益 | 人民币带正负号、收益归属日期、覆盖只数 | 同一对净值日期上的已确认收益合计。计入区间内已清仓基金对该日收益的贡献。没有任何可算项时为 `null`。 |
| 持仓表 | 基金、投资方向、市值、当日收益、持有收益 | 持有收益沿用浮动盈亏，即当前持仓市值减移动加权成本。成本未知为 `null`。首版金额为主；比例仅在成本为正时展示。已实现收益继续单列在已清仓区。 |
| 投资方向 | 至多两条短标签，例如「半导体」「A 股宽基」「电子」「短债」 | 指数和联接基金按已核验的跟踪指数归类；主动权益基金显示最近一期披露行业，并标注报告期与覆盖口径。债券、货币等基金可用明确的产品分类。无可靠依据时显示「暂无方向数据」。列内只展示方向标签。 |

### 当日收益的计算

- 一笔收益属于一个账本、一只基金、一对估值日期。计算输入为未复权确认单位净值及对应账本截止各日期的已确认流水，金额和市值单位都是人民币元。
- 区间按 `(previousDate, valuationDate]` 取流水。公式为 **期末市值 − 期初市值 + 区间外部现金流**。沿用 `toCashFlows` 的符号，申购为负，赎回净额、现金分红为正。红利再投和份额折算用 `derivePosition` 反映到期末份额，不重复加现金流。
- 净值日与抓取日分开。对当前有份额基金，合并各自不晚于中国时区当前日的已确认净值日期。取最近日为 `D`，次近日为 `D0`。两日期随响应返回，为整本账提供统一的估值窗口。有份额的一端缺对应日期净值时，该基金退出日收益汇总。某端从流水可确认没有份额时，该端市值为零。
- 基金总市值和表内市值使用同一个 `D`。若 `D` 后还有影响份额或成本的流水，该基金标记「等待对应净值」，退出总市值汇总。持有收益金额及比例沿用同一份可用市值和对应成本。
- 已清仓基金仅在 `(D0, D]` 内有已确认流水或期初仍有份额时参与当日收益。账本全清仓时，以最近一笔已确认赎回的日期为上界，用该日发生赎回的基金来确定 `D` 和 `D0`。没有可用日期时显示「暂无确认净值」，空账本仍显示零市值。
- 当天部分净值未到，显示「部分已确认」及覆盖只数。只拿到历史净值时显示实际归属日。日期之间有延迟或跨市场缺口时，展示完整区间，不把每只基金不同周期的变动相加。
- 净值显示有除息或折算，但账本缺少相应确认流水时，该区间先显示「待核对分红或折算」。事件字段因备源降级缺失时，保留数据不足标记，相关收益不得当成完整数据计入。现金分红归属日与到账日不同且流水无法匹配时，同样保留待核对。
- 总览只展示基于确认净值的数据。首版保留个人流水中的费用口径，因此当日成交费用会反映在净收益中。

## 关键验收案例

| 场景 | 预期 | 任务 |
| --- | --- | --- |
| 期初无持仓，投入 1,000 元并按确认单位净值获得价值 1,000 元的份额 | 当日收益为 0 | 1 |
| 前日市值 100 元，除息后市值 90 元，已确认现金分红 10 元 | 当日收益为 0；漏记分红时显示待核对 | 1、2 |
| 前日 100 份、净值 1 元，折算后 200 份、净值 0.5 元 | 确认折算后当日收益为 0 | 1 |
| 期初市值 100 元，当天全赎、净到账 105 元 | 期末市值为 0，当日收益为 5 元，这笔收益仍计入账本 | 1、2 |
| 两只基金分别更新到不同净值日 | 总览只加相同日期窗口内可核验的基金，并显示部分已确认 | 2、3 |
| 年初当年披露还没有行业配置 | 可取上年已披露数据，并显示真实报告期 | 4 |
| 联接基金没有明确跟踪标的，且无可用披露 | 显示暂无方向数据，不从基金名猜行业 | 4 |
| 主题指数与主动基金行业配置分别显示 | 已核验的半导体指数可标「半导体」；只有「通信」行业配置的主动基金保留「通信」，不能据此标「AI 算力」 | 4 |
| 档案明确分类为中短债的基金没有股票行业配置 | 仍显示「短债」；只有「债券型」时保留大类，缺少期限依据不细分 | 4 |

## 后续 · 申购只填金额

总览、收益及首版板块标签验收后再开独立实施任务。表单先收基金、金额与交易日期；后端按**该笔申购适用的净值日**取确认单位净值。适用日期、净值或实际费用无法确认时允许保存待确认记录，待确认流水不进入持仓和收益。净值齐备后用扣除实际申购费的金额换算份额，允许按回单份额修正，最终确认沿用现有 SQLite 原子写入和同日序号校验。范围包括旧账兼容及重复确认幂等。
