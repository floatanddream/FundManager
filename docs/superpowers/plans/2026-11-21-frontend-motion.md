# 基金工作台动效实施计划

沿用 shadcn Base Nova 的配色、布局和组件。给用户操作及已确认的数据变化加反馈。

## 第一轮 · 基金选择和图表

- `Workspaces.tsx` 和页面 CSS 在选中项反馈底色与勾标记，在右侧仅对新基金的内容做约 180 ms 进场。右侧标题、净值及收益始终绑定当前基金；保留双栏及列表滚动位置。
- `FundDetail.tsx` 和图表 CSS 使用 ECharts 数据点反馈。月份变化使用短淡入，切换基金或复权口径直接展示对应数据，亮暗切换同时更新图表色值。
- 浏览器用离线样本验证快速跨基金选择、键盘进入详情、月份和复权切换。减少动态效果模式下禁用新增动画。

## 第二轮 · 搜索和录入反馈

- 搜索和筛选沿用查询缓存。首屏请求超过约 180 ms 时在原结果区呈现骨架，后续新结果只做短淡入。保持输入焦点。
- `LedgerAction.tsx`、`Subscriptions.tsx` 与 `App.tsx` 将新草稿和确认流水反馈绑定到真实响应。只高亮新草稿和确认后实际变化的资产或收益，金额立即显示确认结果。保留 Sheet 的默认进退场与焦点归还。
- 对投资方向、数据覆盖和来源说明加轻微展开提示，使用现有中性主题。亮暗和窄屏继续使用同一套反馈。

## 验收

运行单元测试、类型与格式检查、Lint 和前端构建。用合成账本和公开基金代码跑亮暗、窄屏、加载、键盘、快速选择、减少动态效果和真实路由的申购确认流程。
